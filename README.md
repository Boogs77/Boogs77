# Hi, I'm Boogs77 👋

I build **8-bit computers around the W65C02S**: a modular computer on a backplane, two complete machines made from its boards, and the BIOS, games, applications and emulator that run on them.

## 🖥️ Computers

| Project | What it is |
| :--- | :--- |
| **[BO6502](https://github.com/Boogs77/BO6502_65C02-based_modular_computer)** | Modular 65C02 computer on a 39-pin backplane: CPU, RAM, ROM, video, serial, keyboard, SD card, audio, joystick and LCD boards |
| **[miniPET](https://github.com/Boogs77/miniPET_65c02)** | Compact computer with a Big LCD display, inspired by the look of the Commodore PET, in a 3D-printed case |
| **[miniVIC](https://github.com/Boogs77/miniVIC_65c02)** | Single-board arcade computer: TMS9918A video, 2x AY-3-8910 stereo, PS/2 keyboard, two joysticks, SD card |

## 💾 Software for the miniVIC

| Project | What it is |
| :--- | :--- |
| **[miniVIC BIOS](https://github.com/Boogs77/miniVIC_bios)** | WozMon, Microsoft BASIC 1977 and a BIOS with an SD programs menu |
| **[miniVIC Games](https://github.com/Boogs77/miniVIC_games)** | 28 games in 65C02 assembly, with stereo music and records on the SD card |
| **[miniVIC Apps](https://github.com/Boogs77/miniVIC_apps)** | Office applications: text editor, spreadsheet, card file, monitor, assembler and more |
| **[BO6502 · miniVIC Emulator](https://github.com/Boogs77/BO6502-miniVIC-emulator)** | Browser emulator that runs the real BIOS, the games and the applications |
